# Agent Note: 可选视觉模型预处理让 DeepSeek 保留对话执行权

Status: implemented

[English](2026-08-19-optional-vision-model-preprocessing.md) | 中文

## 问题

交付的 DeepSeek 对话路由明确只接受文本，但用户需要输入图片，同时不希望把推理、工具执行或最终回复交给另一个模型。任何传给 DeepSeek 的视觉描述都必须能从会话日志中重建，而且图片中的指令不能获得用户原文的权威。

## 决策

`@deepseek-ai/dsh-llm-image-analysis` 是一个可选的预处理插件，提供 `llm-image-analysis` Settings 分节。其 `provider` 和 `model` 字段选择一条辅助路由；同时省略两者即禁用预处理。仅当确切模型元数据明确包含 `image` 输入模态时，已配置路由才可用。Models 页面把该控件放在 DeepSeek 官方模型行内，将 DeepSeek 标记为主要对话与执行模型，并把辅助路由呈现为图片理解增强。打开开关只会显示选择器；选择符合条件的路由会写入这两个字段，关闭增强则会同时取消这两个字段。

视觉模型负责描述图片，但绝不接管对话。获准的 `user/message` 事件持久化之后、模型历史派生之前，串行 `agent/step-input-logged` 监听器会把每条尚未解析且位于 surface 的图片消息发送到视觉路由，并设置 `purpose: 'image-analysis'`。辅助调用不带工具，且必须返回非空、纯文本结果。会话选中的路由通常仍为 DeepSeek，它会收到这段文本，并继续负责推理、工具调用和面向用户的回复。已配置的视觉路由总会处理图片输入，即使选中的对话路由也能读图，从而让用户的路由选择始终保持同一语义。

当选中的对话模型明确支持图片输入，或已配置辅助路由能解析且明确支持图片时，宿主才会准入图片。未知的辅助能力绝不会通过准入。只有这条辅助路由持续可用时，才能为含有当前或待发布图片的会话选择纯文本对话模型；[Web 图片准入的原子性](../bug-fix/2026-07-29-atomic-web-image-admission.md)所记录的逐 agent 排序会保持准入与选择一致。

## 持久性与信任

在分派前，插件会追加 `image-analysis/request`，其中包含确切的已解析调用配置、系统指令和含图片消息。调用成功后会追加 `image-analysis/result`，再追加一条纯文本替代 `user/message`，其 `sourceEventSeqs` 依次引用原始消息、请求和结果。该替代消息只从当前模型历史中移除图片；原始消息和附件仍然可持久化与渲染。运行时不变式会拒绝未配对的结果、重复结果、不含图片的请求来源或错误的替代来源链。

视觉系统指令会把图片内容视为不可信数据，并禁止遵循其中发现的指令。替代消息会再次标记该描述不可信，并把用户原文保存为独立的 JSON 列表。因此，对话模型会把图片派生文本作为被引用的数据接收，而不是用户权威的静默延伸。

任何模型解析、超时、流、结束原因、空输出或非文本输出失败，都会把原始图片留在 surface 上，并在对话模型运行之前停止该步骤。后续步骤可以重试尚未解析的图片。请求与结果事件让成功的预处理可回放；临时内存描述绝不会对模型可见。

## 曾考虑的替代方案

**把图片直接发给 DeepSeek。** 默认 DeepSeek 路由明确只接受文本，绕过其适配器检查会静默宣告它不提供的能力。当选中对话路由的确切元数据与适配器都支持图片时，直接传递图片仍然有效，但它不满足让 DeepSeek 执行后续任务的需求。

**在图片出现时让千问接管整个对话。** 这会把推理、工具选择和最终回复交给辅助模型，在会话中途改变行为，并使选中的 DeepSeek 路由名不副实。辅助调用被刻意限定为从图片到文本的转换。

**根据提供方或模型名称推断视觉能力。** `qwen-vl` 等名称是惯例，不是运行时保证，自定义端点也可以复用这些名称。要求显式 `inputModalities` 会失败关闭，并使选择器与宿主准入保持一致。

**在不记录的情况下把描述传给 DeepSeek。** 这会违反「模型可见即已落账」不变式，也会让恢复、fork、回放和 transcript（文本记录）检查无法解释该请求。请求、结果与替代来源链会在对话调用前持久化。

## 验证

包测试覆盖路由校验、显式模态强制、请求／结果／替代来源链、纯文本输出、重试、超时、释放与真实 Loader 组合。agent loop 测试固定钩子的已落账输入时序和失败后不分派行为；宿主测试固定生效的图片准入与模型选择；Models 页面测试固定 DeepSeek 增强的呈现方式、开关状态、过滤与带 revision 检查的设置写入。无需密钥的组装后 Web 场景会在真实 DeepSeek 模型行中启用图片理解、选择千问并发送图片，证明千问收到该图片、DeepSeek 只收到持久描述，并把 DeepSeek 的回复与原图一起渲染。

## 后果

包含图片的步骤会在 DeepSeek 运行前增加一次模型调用、对应延迟与用量。视觉路由失败会停止整个步骤，而不是在缺失图片上下文的情况下生成回复。把图片转换为文本可能遗漏视觉细节，但保留原始事件使其仍可检查与重试。base bundle 会挂载插件并提供有界的输出与超时默认值，但不配置路由，因此现有纯文本部署不会获得隐式的外部依赖。
